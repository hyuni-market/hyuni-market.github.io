# 혀니마켓 · 아동복 쇼핑 사이트

남대문아동복 최저마진 공동구매 가게 **혀니마켓**의 소개·주문용 정적 웹사이트입니다.
서버 없이 `index.html` 하나로 동작하고, 지금은 **https://hyuni-market.github.io/** 에 올라가 있습니다.

---

## 1. 폴더 구성

```
hyeonmarket/
├── index.html                     화면 전체 (디자인 + 동작)
├── products.js                    상품·브랜드·사이즈표 데이터  ← 수정은 여기만
├── assets/
│   ├── logo.png                   가게 로고 (손글씨 가로형, 배경 투명 · 헤더·푸터)
│   ├── og-logo.png                카톡 공유 미리보기 이미지 1200×630 (크림 배경)
│   ├── logo-icon.png              파비콘·홈화면 아이콘 512×512 (노란 바탕 + 혀)
│   ├── size-minirobe.jpg          미니로브 원본 사이즈표
│   └── catalog/
│       └── sizes/                 브랜드별 사이즈표 (83개 브랜드)
├── preview-*.png                  미리보기 스크린샷 (올리지 않음)
└── tests/verify_site.py           동작 자동 점검 스크립트
```

상품 사진은 **사진 전용 저장소 3곳**에 나눠 담겨 있습니다 (GitHub 1GB 한도 안으로).
`https://raw.githubusercontent.com/hyuni-market/hyuni-assets/main/catalog/{brandId}/001-1.webp`
`https://raw.githubusercontent.com/hyuni-market/hyuni-assets-2/main/catalog/{brandId}/001-1.webp`
`https://raw.githubusercontent.com/hyuni-market/hyuni-assets-3/main/catalog/{brandId}/001-1.webp`
(상품당 상세 사진 최대 12장, **폭 850px WebP q76** · 카드 썸네일 `001-t.webp` **600×600** q76)
어느 브랜드가 어느 저장소에 있는지는 `products.js`의 사진 주소에 그대로 적혀 있습니다.
세 저장소는 브랜드 35개씩 942MB로 균등하게 나눴습니다(1군 hyuni-assets / 2군 hyuni-assets-2 / 3군 hyuni-assets-3).
사진을 바꾸려면 그 브랜드가 들어 있는 저장소의 같은 경로에 올리면 됩니다.

배포는 `index.html`, `products.js`, `assets/` 세 가지만 `deploy-hyeonmarket/` 로 복사해 올립니다.
`preview-*.png`와 `tests/`는 확인용이라 올리지 않습니다.

(오뜨베베는 베베룩·남녀공용 양쪽에 보여서 합계가 전체보다 큽니다.)

### 화면에서 되는 일

- **홈 = 브랜드 폴더**: 브랜드마다 2×2 콜라주(상품 사진 4장) + 브랜드명 + 상품 수 카드.
  모바일 2열, PC 3~4열. 카테고리 탭을 고르면 그 카테고리의 브랜드만 남습니다.
- **브랜드 바로가기**: 검색창 아래 `전체 브랜드 ⌄` 드롭다운에서 브랜드를 고르면 바로 그 브랜드로 이동합니다
  (`고고피크닉 (13)` 처럼 상품 수 표시, 카테고리 탭에 맞춰 목록이 바뀜).
- **품목 필터**: `전체 · 아우터 · 상의 · 하의 · 상하세트 · 원피스 · 실내복 · 주니어`
  홈에서 누르면 브랜드 카드 대신 그 품목 상품이 바로 나오고(카테고리 탭과 함께 적용),
  브랜드 안에서는 그 브랜드의 품목별 개수와 함께 표시됩니다. `주니어`는 JS·JM·JL·15~21호·140~165 사이즈 상품입니다.
- **검색**: `브랜드, 상품명 검색` — 검색어를 넣으면 브랜드 카드 대신 **맞는 상품이 바로** 나옵니다.
- **정렬·초성**: `가나다순` / `상품많은순`, `전체 ㄱ ㄴ ㄷ … ㅎ` (해당 브랜드가 없는 초성은 흐리게 표시).
- **브랜드 안**: `← 브랜드 목록으로` · 브랜드명 · `N개 상품` · `📏 사이즈표`(있는 브랜드만) + 상품 2~4열 목록.
  60개씩 보여주고 `상품 더 보기`로 이어집니다.
  아래쪽 어디서든 왼쪽 아래 **`← 뒤로` 플로팅 버튼**으로 브랜드 목록에 돌아올 수 있고,
  아이폰 **뒤로가기·왼쪽에서 오른쪽 스와이프**도 그대로 동작합니다(모달 → 브랜드 → 홈 순서).
- **상품 상세**: 상세 사진 여러 장, 색상·사이즈 선택, **선택한 옵션** 목록, `총 N원 · 장바구니 담기`,
  브랜드 원본 사이즈표(있으면) 바로 아래 표시.
  - 색상과 사이즈를 고르면 **선택한 옵션**에 `색상 / 사이즈 · 수량 · 금액` 줄이 추가되고, 색상·사이즈 선택은 비워집니다.
  - 그래서 **형제 옷을 여러 벌(다른 색·다른 사이즈)** 한 번에 담을 수 있습니다. 줄마다 `− 1 +`, `×` 삭제.
  - 이미 고른 색상·사이즈를 한 번 더 누르면 **선택이 해제**됩니다.
- **장바구니**: 수량 +/−, 삭제, `일반 배송(3,500원)` / `합배송(0원)`, 합계 자동 계산, `주문서 복사하기`.
  **상품 사진이나 이름을 누르면 그 상품 상세로 이동**합니다(수량·삭제 버튼은 그대로 동작).
  담긴 상품이 있으면 오른쪽 아래에 카라멜색 **플로팅 장바구니** 버튼이 떠서 언제든 열 수 있습니다.
- **주문서 복사**: 1:1 채팅방에 붙여넣을 형태로 복사되고, 맨 아래 `성함·연락처·주소` 칸을 고객이 채워 보냅니다.
  복사하면 화면 위쪽에 짧은 안내 토스트가 뜹니다.

## 3. 상품·브랜드 추가하는 방법

`products.js`의 `products` 배열에 한 덩어리만 넣으면 목록·상세·장바구니·주문서에 자동 반영됩니다.

```js
{
  id: 'newbrand-item-001',        // 겹치지 않는 이름
  brandId: 'newbrand',            // brands의 id
  brand: '새브랜드',
  name: '상품 이름',
  price: 29000,                   // 숫자만 (원) — 공급가 + 3,000원
  categories: ['girl'],           // bebe · girl · unisex · acc · shoes
  itemType: 'outer',              // outer · top · bottom · set · dress · homewear · etc
  colors: ['베이지', '브라운'],
  colorHex: { '베이지': '#d9b98f', '브라운': '#6b4a37' },
  sizes: ['S', 'M', 'L'],
  sizeAdd: { 'L': 2000 },         // 사이즈별 추가금이 있을 때만
  thumb: 'assets/catalog/newbrand/001-t.jpg',   // 카드 썸네일(정사각)
  image: 'assets/catalog/newbrand/001-1.jpg',   // 상세 첫 사진
  detailImages: ['assets/catalog/newbrand/001-1.jpg', '001-2.jpg'],  // 상세 갤러리
  description: ['색상 · 베이지 / 브라운', '사이즈 · S / M / L']
}
```

브랜드는 `brands` 배열에 추가합니다. `sizeImage`(원본 사이즈표)나 `sizeTable`(표)이 있으면
사이즈표 버튼과 상세 인라인 사이즈표가 자동으로 생기고, 없으면 버튼이 나오지 않습니다.

```js
{
  id: 'newbrand',
  name: '새브랜드',
  nameEn: 'NEW BRAND',
  categories: ['girl'],
  sizeImage: 'assets/catalog/sizes/newbrand.jpg',
  sizeNote: '측정 방법에 따라 1~2cm 차이가 날 수 있어요.'
}
```
